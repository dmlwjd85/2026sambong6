# 수업도구 보드게임

학급 메타버스 수업도구의 **보드게임** 영역입니다. 오목·체스가 이 공통 방 위에 올라가 있습니다.

## 다음 보드게임을 넣을 때

1. `BOARD_GAME_CATALOG` (`src/lib/boardGameRooms.js`)에 게임 한 줄을 추가합니다.  
   `id`, `label`, `minPlayers`, `maxPlayers`, `timerSec`만 넣으면 로비·정원·방치 TTL이 그대로 동작합니다.
2. 승패·착수 등 게임 고유 로직은 `gomokuGame.js`처럼 **순수 모듈 + `*.test.js`** 로 만듭니다.
3. Firestore 경로는 공통입니다.

```
artifacts/{학급ID}/public/data/boardGameRooms/{roomId}
```

4. 화면은 `data-tool="boardgames"` 한 창에서 게임 카드 → 방 목록 → 대국 화면으로 전환합니다.  
   `sambongWorld.js`의 `boardGame*` 함수를 새 게임에 연결하면 됩니다.

## 공통 규칙 (학급용)

| 항목 | 동작 |
|------|------|
| 방장 | 방을 만든 학생(또는 선생님). 학번(`sambong_student_id`)으로 식별합니다. |
| 참가 | 다른 학생이 신청 → 방장이 승인/거절. 정원이 차면 시작합니다. |
| 30초 타이머 | **방장만** 켜고 끌 수 있습니다. 켜져 있으면 각 턴 30초, **시간 초과 시 그 턴 플레이어 패배**(패스 없음). |
| 종료 후 | 같은 방에서 **다시 두기**(자리 유지) 또는 **방 종료**(목록에서 제거). |
| 나가기 | 대국 중 나가면 **본인 패배 / 상대 승리**. 확인 창을 띄웁니다. |
| 방 정리 | 다른 방에 들어가거나 방을 새로 만들면, 내가 방장으로 연 대기 방과 다른 참가 대기는 지웁니다. |
| 전적 | 학생 문서 `boardGameRecords.gomoku` / `boardGameRecords.chess`에 승/패/무를 따로 셉니다. |
| 방치 | `lastActivityAt` 기준 **10분** 무활동이면 자동 종료되어 목록에 남지 않습니다. |

## 오목

- 20×20. **흑만 3·3(열린 삼이 두 갈래) 금지**. 백은 3·3을 둘 수 있습니다. 장목·4-4 금수는 쓰지 않습니다. 방장=흑(선공). 예전 15×15 방 문서는 `cells` 길이(225)로 판 크기를 맞춥니다.
- 다섯 목(이상)이면 승리, 판이 가득 차면 무승부. PVP와 AI 대전 모두 같은 규칙을 씁니다.
- 스마트폰: 핀치 확대/축소, 칸을 고른 뒤 **여기 두기**로 확정. 웹은 마우스 클릭으로도 칸을 고릅니다.
- 「여기 두기」는 고른 돌 옆에 한 줄로 뜨고, 가장자리에서도 화면 안에 남습니다. 눌러도 줌·팬은 유지됩니다.
- **AI와 두기**: Firestore 방 없이 로컬에서 혼자 둡니다. 당신은 흑, AI는 백. 로비에서 **고수**/**초인**을 고릅니다.
  - **고수**: 예전 「강함」과 같은 강도. 열린 4·3 차단과 한 수 앞(2-ply).
  - **초인**: 위협 수(연속 4, VCF류)와 더 깊은 탐색(반복 심화 알파베타). 턴당 약 2~3초 상한, Web Worker로 UI가 멈추지 않게 합니다. 백의 3·3을 공격에 쓸 수 있습니다.
- AI 종료 후 **다시 두기** / **종료**는 PVP와 같은 막대입니다. PVP 방 만들기·참가 흐름은 그대로입니다.

## 체스

- 8×8 정식 규칙. 방장=백(선공). 캐슬링·앙파상·프로모션(퀸/룩/비숍/나이트 선택)·체크·체크메이트·스테일메이트, 50수·기물 부족·3회 반복 무승부.
- 말을 고르면 **갈 수 있는 칸은 연한 점**, **잡을 수 있는 칸은 빨간 고리**로 표시합니다. 목적지를 고른 뒤 **여기 두기**를 눌러야 이동합니다. 마지막 수는 노란 테두리, 체크된 킹은 빨간 테두리입니다.
- 기물은 상아/흑철 SVG이고 칸을 거의 채웁니다. 판은 나무·금속 테두리와 a~h / 1~8 좌표가 있습니다. 잡을 때 기물별 짧은 이펙트와 진동이 납니다.
- 스마트폰·웹 모두 칸을 크게 두고, 내가 흑이면 판을 뒤집어 내 말이 아래에 오게 합니다.
- **AI와 두기**: 로비에서 내가 백/흑을 고른 뒤 **고수**/**초인**. 기본은 학생=백.
  - **고수**: 고정 깊이 3 알파베타 + 짧은 정지탐색. 한 수 약 1초, Web Worker.
  - **초인**: 강함 우선. 오프닝북은 건전한 주요 라인만(처음 몇 수). 북을 벗어나면 탐색 최선 수(동점 약 10cp만 제한적으로 섞음). PeSTO·킹 안전·폰 구조·패스드 폰·비숍 페어·엔드게임 킹·전치표(같은 대국에서 유지)·킬러/히스토리·널무브·LMR·aspiration·체크 연장·SEE 정지탐색. 한 수 약 3.5초(최대 4초), Web Worker.
- 나가기=기권 패, 전적·방 정리·30초 타이머는 오목과 같은 공통 방을 씁니다.
- **체스 배우기**: 체스 방 목록의 「📖 체스 배우기」. 12단원(판과 말 → 룩·비숍·퀸·나이트·킹·폰 → 체크와 벗어나기 → 체크메이트 → 비기는 경우 → 캐슬링·앙파상 → 마무리 문제)을 작은 판에서 직접 한 수씩 둬 보며 배워요.
  - 문제와 정답 판정은 순수 모듈 `chessLessons.js`(+ 테스트)에 있고, 둘 수 있는 수·체크메이트 판정은 대국과 같은 `chessGame.js`를 써요. 화면은 `../chessTutorial.js`, `../chessTutorial.css`.
  - 가야 할 칸은 별, 움직일 말은 살짝 들썩여 알려 주고, 두 번 틀리면 정답 칸을 초록 테두리로 보여 줘요. 맞히면 OX 퀴즈와 같은 소리·진동이 나요.
  - 방·Firestore를 쓰지 않아요. 끝낸 단원은 기기(localStorage `sambong_chess_learn_v1`)에만 저장돼요. 모두 마치면 「AI 고수와 두기」가 보여요.

## 알까기 (준비 중)

- 물리는 순수 모듈 `alkkagiPhysics.js`(+ `alkkagiPhysics.test.js`)에 있어요. 고정 dt 1/120초, 쿨롱식 마찰, 원-원 충격량 충돌, 서브스텝 터널링 방지, 판 밖 탈락, id 순 처리와 반올림으로 결정적이에요.
- 입력 API는 `shot(id, angle, power)`이고 power는 0..1(상한 1)이에요.
- **조준선·힘 게이지·예상 경로·숫자는 화면에 표시하지 않아요.** 선생님 요청이에요. 당긴 방향·거리로 각도와 힘을 계산해 모듈에만 넘기고, 화면에는 알이 살짝 눌리거나 그림자가 지는 손맛 표현만 둬요.

### 실시간 알까기 (`alkkagiLive`)

- 판을 시작하면 가운데에 **3 → 2 → 1 → 시작!** 을 세고, 그동안은 아무도 못 쏴요(사람끼리·AI 대전 모두). 기기 시계가 서로 달라도 어긋나지 않게 각 기기가 판을 처음 받은 때부터 최대 3초만 세요(`liveCountdownEndAt`). 이미 누가 쏜 판(새로고침)은 바로 이어 해요.
- 차례 없이 두 사람이 동시에 쏴요. **한 사람당 3초에 한 번** 쏠 수 있고, 남은 시간은 상단 알약·이름 카드 막대·내 알 둘레 고리로 보여요.
- 방 문서(`boardGameRooms/alkl_{방장}`)는 기존 방 흐름(만들기·참가 승인·기권·다시 하기·닫기)을 그대로 써요. 자주 바뀌는 판은 하위 컬렉션 `live`에만 써서 로비 구독 비용이 늘지 않아요.
  - `live/state`: 방장 기기가 계산한 판 스냅샷(gid·seq·epoch·hostSeat·돌 좌표/속도·반영한 샷 번호). 샷 반영·멈춤·판 끝 때만, 최소 250ms 간격으로 써요.
  - `live/black`, `live/white`: 자리마다 문서 하나를 덮어써요. 샷 의도(번호 n+1)와 접속 표시(seenAt). 규칙이 서버 시각으로 첫 샷 뒤 2초 간격을 강제해요(방장 기기는 받은 시각으로 1.8초). 화면 쿨다운은 3초라, 인터넷 지연이 1초 남짓 흔들려도 거절되지 않아요(#106).
  - 샷 의도 쓰기가 거절되면 0.7초 뒤 같은 샷을 한 번 더 보내요. 두 번째도 실패할 때만 '샷이 전달되지 않았어요'를 보여요.
  - 상대(게스트)는 내 샷이 아직 방장 판에 들어가지 않은 동안 방장의 중간 판으로 되돌리지 않고 최대 1.2초 기다려요. 같은 알이 다른 자리에서 두세 번 굴러가거나 겹쳐 보이던 현상을 막아요.
- 물리 권위는 방장 기기예요. 상대는 자기 샷을 화면에 먼저 굴리고(예측) 의도만 보낸 뒤, 방장 스냅샷이 오면 그 판으로 맞춰요. 좌표는 반올림 없이(물리의 6자리) 보내 두 화면이 같은 판으로 멈춰요.
- 상대 알을 모두 떨어뜨리면 승, 마지막 알이 함께 떨어지면 무승부, 나가기는 기권 패. 전적은 알까기 전적에 함께 쌓여요.
- **실시간 AI와 하기**: 로비 「실시간 AI」에서 쉬움/보통/고수를 골라요. 방 문서·Firestore 없이 내 기기에서만 돌아요. 나는 검은 알, AI는 흰 알이고 둘 다 3초에 한 번씩 동시에 쏴요.
  - 판 계산은 같은 세션(`alkkagiLiveSession.js`)을 내 기기에서 방장으로 돌리고, AI 샷은 상대 자리 문서처럼 넣어요. 그래서 쿨다운·살아 있는 알 확인·판 끝 판정이 사람끼리 할 때와 같아요.
  - 어디에 쏠지는 턴제 AI(`alkkagiAi.js`)를 그대로 쓰고, 언제 쏠지는 `alkkagiLiveAi.js`가 정해요. 쿨다운이 끝나면 난이도만큼 머뭇거려요(쉬움 2.6~4.4초, 보통 1.2~2.4초, 고수 0.3~0.9초). 알이 굴러가면 조금 더 기다려요.
  - AI 대전은 전적에 들어가지 않고, 새로고침하면 끝나요. 결과 화면의 「그만할래요」는 로비로 돌아가요.
- 모듈: `alkkagiLiveGame.js`(규칙·형식), `alkkagiLiveEngine.js`(실시간 물리 진행), `alkkagiLiveSession.js`(방장/상대 동기화), `alkkagiLiveBoard.js`(캔버스), `../alkkagiLiveMode.js`(화면 컨트롤러).

## 이심전심 (더 마인드 규칙)

- 2~4명이 한 팀이 되어, 말 없이 작은 수부터 카드를 내는 협동 게임이에요. 시중 보드게임 「더 마인드」와 같은 규칙이에요.
  - 레벨 N에서 1~100 카드 중 N장씩 받아요. 차례 없이, 자기 손에서 가장 작은 카드를 내요.
  - 낸 카드보다 작은 카드를 든 사람이 있으면 생명 1개를 잃고, 그보다 작은 카드를 모두 치워요.
  - 레벨 수: 2명 12, 3명 10, 4명 8. 시작 생명은 사람 수, 수리검 1개. 2·5·8레벨 통과 시 수리검 +1, 3·6·9레벨 통과 시 생명 +1(생명 5개, 수리검 3개까지).
  - 수리검은 한 사람이 제안하고 모두 동의하면 각자 가장 작은 카드를 보이게 버려요. 레벨마다 모두 「준비됐어요」를 눌러야 시작해요.
- 방은 공통 방(`gameType: 'mind'`, 2~4명)을 써요. 4명이 차면 바로 시작하고, 2~3명이면 방장이 목록에서 「시작하기」를 눌러요. 서버 규칙은 바꾸지 않았어요.
- 규칙·판정은 순수 모듈 `mindGame.js`(+ 테스트), 화면은 `../mindMode.js`, `../mindMode.css`예요. 카드를 낼 때마다 방 문서를 트랜잭션으로 고쳐서, 거의 같이 눌러도 먼저 닿은 쪽부터 판정돼요.
- 손패는 방 문서(`game.hands`)에 함께 들어 있고 화면은 자기 손패만 보여 줘요. 한 팀 게임이라 승패 전적은 세지 않아요.
- 하다가 나가면 팀 도전이 끝나요. 방장이 아닌 사람이 나가면 자리도 비워서, 남은 사람이 2명 이상이면 「한 판 더」를 할 수 있어요.
