# 수업도구 보드게임

학급 메타버스 수업도구의 **보드게임** 영역입니다. 오목·체스가 이 공통 방 위에 올라가 있습니다.

## 다음 보드게임을 넣을 때

1. `BOARD_GAME_CATALOG` (`src/lib/boardGameRooms.js`)에 게임 한 줄을 추가합니다.  
   `id`, `label`, `minPlayers`, `maxPlayers`, `timerSec`만 넣으면 로비·정원·방치 TTL이 그대로 동작합니다.
2. 승패·착수 등 게임 고유 로직은 `gomokuGame.js`처럼 **순수 모듈 + `*.test.js`** 로 만듭니다.
3. Firestore 경로는 공통입니다.

```
artifacts/{학급ID}/public/data/boardGameRooms/{roomId}
```

4. 화면은 `data-tool="boardgames"` 한 창에서 게임 카드 → 방 목록 → 대국 화면으로 전환합니다.  
   `sambongWorld.js`의 `boardGame*` 함수를 새 게임에 연결하면 됩니다.

## 공통 규칙 (학급용)

| 항목 | 동작 |
|------|------|
| 방장 | 방을 만든 학생(또는 선생님). 학번(`sambong_student_id`)으로 식별합니다. |
| 참가 | 다른 학생이 신청 → 방장이 승인/거절. 정원이 차면 시작합니다. |
| 30초 타이머 | **방장만** 켜고 끌 수 있습니다. 켜져 있으면 각 턴 30초, **시간 초과 시 그 턴 플레이어 패배**(패스 없음). |
| 종료 후 | 같은 방에서 **다시 두기**(자리 유지) 또는 **방 종료**(목록에서 제거). |
| 나가기 | 대국 중 나가면 **본인 패배 / 상대 승리**. 확인 창을 띄웁니다. |
| 방 정리 | 다른 방에 들어가거나 방을 새로 만들면, 내가 방장으로 연 대기 방과 다른 참가 대기는 지웁니다. |
| 전적 | 학생 문서 `boardGameRecords.gomoku` / `boardGameRecords.chess`에 승/패/무를 따로 셉니다. |
| 방치 | `lastActivityAt` 기준 **10분** 무활동이면 자동 종료되어 목록에 남지 않습니다. |

## 오목

- 20×20. **흑만 3·3(열린 삼이 두 갈래) 금지**. 백은 3·3을 둘 수 있습니다. 장목·4-4 금수는 쓰지 않습니다. 방장=흑(선공). 예전 15×15 방 문서는 `cells` 길이(225)로 판 크기를 맞춥니다.
- 다섯 목(이상)이면 승리, 판이 가득 차면 무승부. PVP와 AI 대전 모두 같은 규칙을 씁니다.
- 스마트폰: 핀치 확대/축소, 칸을 고른 뒤 **여기 두기**로 확정. 웹은 마우스 클릭으로도 칸을 고릅니다.
- 「여기 두기」는 고른 돌 옆에 한 줄로 뜨고, 가장자리에서도 화면 안에 남습니다. 눌러도 줌·팬은 유지됩니다.
- **AI와 두기**: Firestore 방 없이 로컬에서 혼자 둡니다. 당신은 흑, AI는 백. 로비에서 **고수**/**초인**을 고릅니다.
  - **고수**: 예전 「강함」과 같은 강도. 열린 4·3 차단과 한 수 앞(2-ply).
  - **초인**: 위협 수(연속 4, VCF류)와 더 깊은 탐색(반복 심화 알파베타). 턴당 약 2~3초 상한, Web Worker로 UI가 멈추지 않게 합니다. 백의 3·3을 공격에 쓸 수 있습니다.
- AI 종료 후 **다시 두기** / **종료**는 PVP와 같은 막대입니다. PVP 방 만들기·참가 흐름은 그대로입니다.

## 체스

- 8×8 정식 규칙. 방장=백(선공). 캐슬링·앙파상·프로모션(퀸/룩/비숍/나이트 선택)·체크·체크메이트·스테일메이트, 50수·기물 부족·3회 반복 무승부.
- 말을 고르면 **갈 수 있는 칸은 연한 점**, **잡을 수 있는 칸은 빨간 고리**로 표시합니다. 목적지를 고른 뒤 **여기 두기**를 눌러야 이동합니다. 마지막 수는 노란 테두리, 체크된 킹은 빨간 테두리입니다.
- 기물은 상아/흑철 SVG이고 칸을 거의 채웁니다. 판은 나무·금속 테두리와 a~h / 1~8 좌표가 있습니다. 잡을 때 기물별 짧은 이펙트와 진동이 납니다.
- 스마트폰·웹 모두 칸을 크게 두고, 내가 흑이면 판을 뒤집어 내 말이 아래에 오게 합니다.
- **AI와 두기**: 로비에서 내가 백/흑을 고른 뒤 **고수**/**초인**. 기본은 학생=백.
  - **고수**: 고정 깊이 3 알파베타 + 짧은 정지탐색. 한 수 약 1초, Web Worker.
  - **초인**: 오프닝북(여러 계열)·가까운 후보 가중 무작위 + 더 깊은 탐색(전치표·히스토리·널무브·LMR). 한 수 최대 약 3초, Web Worker.
- 나가기=기권 패, 전적·방 정리·30초 타이머는 오목과 같은 공통 방을 씁니다.
