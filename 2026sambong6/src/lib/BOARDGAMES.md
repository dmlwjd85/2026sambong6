# 수업도구 보드게임

학급 메타버스 수업도구의 **보드게임** 영역입니다. 오목은 이 공통 방 위에 올린 첫 게임입니다.

## 다음 보드게임을 넣을 때

1. `BOARD_GAME_CATALOG` (`src/lib/boardGameRooms.js`)에 게임 한 줄을 추가합니다.  
   `id`, `label`, `minPlayers`, `maxPlayers`, `timerSec`만 넣으면 로비·정원·방치 TTL이 그대로 동작합니다.
2. 승패·착수 등 게임 고유 로직은 `gomokuGame.js`처럼 **순수 모듈 + `*.test.js`** 로 만듭니다.
3. Firestore 경로는 공통입니다.

```
artifacts/{학급ID}/public/data/boardGameRooms/{roomId}
```

4. 화면은 `data-tool="boardgames"` 한 창에서 게임 카드 → 방 목록 → 대국 화면으로 전환합니다.  
   `sambongWorld.js`의 `boardGame*` 함수를 새 게임에 연결하면 됩니다.

## 공통 규칙 (학급용)

| 항목 | 동작 |
|------|------|
| 방장 | 방을 만든 학생(또는 선생님). 학번(`sambong_student_id`)으로 식별합니다. |
| 참가 | 다른 학생이 신청 → 방장이 승인/거절. 정원이 차면 시작합니다. |
| 30초 타이머 | **방장만** 켜고 끌 수 있습니다. 켜져 있으면 각 턴 30초, **시간 초과 시 그 턴 플레이어 패배**(패스 없음). |
| 종료 후 | 같은 방에서 **다시 두기**(자리 유지) 또는 **방 종료**(목록에서 제거). |
| 방치 | `lastActivityAt` 기준 **10분** 무활동이면 자동 종료되어 목록에 남지 않습니다. |

## 오목

- 20×20, 자유 오목(렌주 금수 없음). 방장=흑(선공). 예전 15×15 방 문서는 `cells` 길이(225)로 판 크기를 맞춥니다.
- 다섯 목(이상)이면 승리, 판이 가득 차면 무승부.
- 스마트폰: 핀치 확대/축소, 칸을 고른 뒤 **여기 두기**로 확정. 20×20도 줌으로 집을 수 있게 합니다.
- **AI와 두기**: Firestore 방 없이 로컬에서 혼자 둡니다. 당신은 흑, AI는 백(강함). 열린 4·3 차단과 한 수 앞을 봅니다.
- AI 종료 후 **다시 두기** / **종료**는 PVP와 같은 막대입니다. PVP 방 만들기·참가 흐름은 그대로입니다.
