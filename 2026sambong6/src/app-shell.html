출석의 축복

담임·보조 교사가 오늘 상태를 고릅니다. 출석 +8XP +1봉, 지각(오전 9시 이후) -5XP, 조퇴 -5XP, 결석 -10XP. 같은 버튼을 다시 누르면 오늘 기록을 되돌립니다. 조퇴·결석은 광장 카드가 흐려집니다.

체크리스트

학급 인원수만큼 번호가 있는 판입니다. 번호를 누르면 제출 완료가 되고 +20XP +2봉이 지급됩니다. 다시 누르면 제출과 보상이 되돌아갑니다. 끝나면 판을 지울 수 있습니다.

퀘스트 통계

퀘스트 완료율, XP 상위, 퀘스트별 완료 Top 3, 상점·은행 이용을 봅니다.

퀘스트 항목 관리

기본 퀘스트는 숨김 처리되고, 추가 퀘스트는 삭제됩니다. 이미 학생에게 기록된 과거 퀘스트 이력은 보존됩니다.

    기능 역량/성취기준 연결표입니다. 연구·타당성 증빙에 활용하세요.

    설정을 열면 불러옵니다.

    6. 운영 기본값

    평일 1~6교시 시작·종료 시각에 학교종 멜로디와 팝업이 나옵니다. 팝업은 10초 뒤 사라집니다. 이 컴퓨터 시계를 쓰며, 학급 전체가 아니라 이 기기에만 적용됩니다.

    기능 해금

    새 학급은 홈·광장·퀘스트·직업·헌법·도움말만 켜져 있습니다. 사용법을 익힌 뒤 아래에서 하나씩 여세요. 기존 삼봉 교실은 모든 기능이 이미 열려 있습니다.

    외부 세계 링크

    새 학급은 이전 교실의 외부 링크를 가져오지 않습니다. 이 반에서 쓸 주소만 넣으세요.

    도움말

    시작 가이드 · 학생 이용 · 차별화 · FAQ · 개인정보 · 출처 v1.2

    선생님 시작 가이드 (6단계)

    1. 새 학급 만들기 → 학급명·시즌·마스터 이름 입력
    2. 초대 코드 복사해서 학생에게 공유
    3. 마스터로 로그인 후 명단 입력
    4. 기본 템플릿 적용 (선택)
    5. 설정 → 기능에서 문학·경제·도전 등을 하나씩 해금
    6. 헌법을 우리 반 약속에 맞게 고친 뒤 수업 시작

    학생 이용 방법

    1. 로그인 화면에서 「학생」 선택
    2. 선생님이 알려준 초대 코드 입력 → 학급 열기
      또는 공유 링크 ?c=코드 로 바로 입장
    3. 내 이름 선택 후 PIN 4자리로 접속 (처음 입력이 비밀번호)
    4. 퀘스트·문학(독서기록장·일기장)·경제(상점·은행·부동산)·직업·도전 등 탭에서 활동

    ClassDojo와 다른 점

    MATE는 단순 행동 점수 앱이 아닙니다. 학급 경제(봉)·직업·헌법·도전(골든벨·퀴즈·레이드)·시즌이 한 메타버스로 연결되어, 교실을 ‘살아있는 사회 시뮬레이션’으로 운영합니다. 학급마다 데이터가 완전히 분리됩니다.

    다교실·1000학급 구조

    • 앱 주소는 하나, 학급은 초대 코드(?c=)로 구분
    • 메타: classes/{학급ID} · 게임 데이터: artifacts/{학급ID}/...
    • 매핑: inviteCodes/{코드} → 학급ID (빠른 입장)
    • 초기화·보관은 현재 학급만 — 다른 반에 영향 없음
    • 대규모 운영 시 Firebase Blaze + 예산 알림 권장

    자주 묻는 질문

    • Q. 초대 코드가 안 열려요. A. 대소문자·공백을 확인하고, 네트워크를 점검한 뒤 다시 시도하세요. 보관된 학급은 입장할 수 없습니다.
    • Q. 학급마다 다른 주소를 줄 수 있나요? A. 네. 「접속 링크 복사」하면 ?c=초대코드 형태 링크가 복사됩니다.
    • Q. 다른 반으로 바꾸려면? A. 상단 학급 메뉴에서 전환하거나, 다른 초대 코드 링크로 접속하세요.
    • Q. 게스트는? A. 구경만 가능하며 실제 데이터는 변경되지 않습니다.
    • Q. 레이드 비밀번호는? A. 마스터 탭 「퀘스트」 상단에서 바꿉니다. 기본 1234는 사용하지 않습니다.
    • Q. 학급게시판은? A. 수업도구에서 교사가 발문과 시간을 열면 학생이 쪽지로 바로 제출합니다. 페이지 넘김은 이전 쪽지를 남기고 새 페이지를 엽니다. 「함께 보기」를 켜면 작성이 멈추고 화면만 봅니다.
